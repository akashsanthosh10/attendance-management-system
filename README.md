# Attendance Management System

## Overview

The **Attendance Management System** is a Flutter-based mobile application designed to facilitate efficient attendance marking for students in educational institutions. It leverages Firebase for authentication, data storage, and real-time updates.

## Features

- **Login System**: Secure user login with Firebase Authentication using email and password.
- **Course Selection**: Users can select courses to mark attendance.
- **Student Management**: Add new students, view their details, and mark their attendance.
- **Attendance Marking**: Track student attendance by selecting a checkbox for each student.
- **Data Storage**: Store attendance records and student details in Firebase Firestore.

## Requirements

To run this application, you need:

- **Flutter**: Version 2.0 or higher
- **Firebase Account**: Firebase Authentication and Firestore set up in the Firebase Console
- **FlutterFire Plugins**: `firebase_core`, `firebase_auth`, and `cloud_firestore`
